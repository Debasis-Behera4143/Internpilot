System Settings & Administration

Administrative controls and configuration

Platform Administrators

Admin accounts are securely seeded via environment variables (ADMIN_EMAIL, ADMIN_PASSWORD) or granted through the Users table. Passwords use Bcrypt (12 rounds) hashing.

Role Enforcement: Server-Side RBAC (require_admin dependency)

Session & Security Controls

JWT access tokens expire every 120 minutes. All sign-out events immediately register tokens into the SHA-256 database blacklist table to prevent replay.
